# 발표 양식 PPT 문구

## 자동화 흐름 (AI 적용 전/후 Workflow)

**As-Is (모든 단계를 사람이 수행 · 건당 5~10분)**

> 메일로 COA 수신 → PDF 열어 규격서와 눈으로 대조 → ppm·% 단위 수기 환산 → ERP 수기 입력 → 이상 시 협력사 메일 직접 작성

**To-Be (메일 도착부터 판정까지 자동 · 사람은 예외 건만)**

> Outlook 새 메일 즉시 감지 → 첨부 PDF 자동 저장(표준 파일명) → 항목·값·단위 추출 → 단위 자동 환산(Decimal) → 사내 규격 자동 판정(적합/부적합/검토 필요) → 결과 DB·엑셀·ERP 업로드 양식 자동 생성 → 부적합·검토 필요 건만 담당자 알림 + 협력사 통보서 초안

한 줄 요약: **"AI·파서는 읽기만, 판정은 정해진 규칙대로 코드가 — 모르면 추측하지 않고 사람에게."**

## 소요시간 / 수행주기

| 구분 | As-Is | To-Be |
| --- | --- | --- |
| 소요시간 | **5~10분/건** (첨부 열기 + 대조 + 단위 환산 + ERP 입력) | **예외 건만 1분 이내** (적합 건은 사람 작업 0분, 메일 도착 후 수 초 내 판정) |
| 수행주기 | **일** (입고 COA 수신 시마다) | **일** (메일 수신 시 자동) |

연간 절감(예시, 실제 건수로 교체): 일 20건 × 건당 7분 × 연 250일 ≈ **583시간/년**

## 함께 쓸 수 있는 짧은 문구

- 판정 시점: 담당자가 메일함을 열 때 → **메일 도착 즉시(수 초)**
- 판정 근거: 합격 도장만 → **항목별 원문 값·환산 값·규격·사유·Spec 버전 이력**
- 감사 대응: 폴더·메일함 탐색 수 시간 → **Lot 번호 검색 수 초**
- 품질 리스크: "자동화가 100 % 맞다"가 아니라 **사람의 최종 확인을 돕는 이중 검증**
